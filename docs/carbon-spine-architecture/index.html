The mental model

Five stacked layers

Each layer is derived from the one above it. Only the top layer is authoritative. Everything below can be deleted and rebuilt.

1

Durable facts

ECS entities carrying durable Carbon components: BUID identity, parentage, payload, provenance, Representation Markers, generation metadata. This is the only authority. Nothing below is required to recover it.

2

Spine

The logical hierarchy and its rebuildable indexes: ancestry, children, subtree, scope, pruning. The hierarchy is durable because parentage is durable. The indexes that make it fast are not.

3

Control

Coordinator, Publication, Watcher, Orchestrator. Mutation, settlement, localization, and desired-state derivation. These systems hold no authority of their own; they move truth and describe it.

4

Contextual working state

Scope-owned systems, caches, target sets, binding buckets, dirty sets, pending operations. All of it disposable, all of it owned by the Context Scope that gives it meaning.

5

Projection

Reconcilers, delivery packages, manifests, presenters, GameObjects, Scenes, physics, audio, rendering. Expensive, asynchronous, stateful, useful — and never durable.

Durable truth says what exists and where. Everything else discovers, interprets, caches, simulates, or represents that truth.
Runtime consequences are derived from durable change rather than being manually orchestrated by the endpoint that requested the change.
§31

Failure semantics

A functional system needs an explicit answer for each of these. The common thread: a projection failure never rewrites durable truth.

§36

Implementation order

Build bottom-up. Each phase is provable on its own before the next one has anything to stand on.
