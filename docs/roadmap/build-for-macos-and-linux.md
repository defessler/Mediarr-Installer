# Build for macOS and Linux

## What

Produce macOS (arm64 and x64) and Linux x64 AppImage builds of the installer, with CI for them.

## Why

Windows x64 is the primary target. The other platforms were planned for phase 3.

## Done when

CI builds the macOS and Linux artifacts.
