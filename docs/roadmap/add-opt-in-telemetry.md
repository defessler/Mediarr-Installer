# Add opt-in telemetry

## What

Add opt-in, anonymous failure reports from the installer.

## Why

It was listed as a phase 3 nicety, to learn about install failures that users don't report.

## Done when

A user can opt in to anonymous failure reports, and nothing is sent without that choice.

## Notes

Phase 3, estimated 3h. This repo is public, so keep any endpoint details out of it.
